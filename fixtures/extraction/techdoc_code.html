Configuring the cache layer

The cache layer stores parsed responses keyed by URL fingerprint. Enable it in the configuration file and choose an eviction policy.

[cache]
enabled = true
max_entries = 5000
eviction = "lru"

The max_entries limit applies per worker process. When the limit is reached the least recently used entry is evicted first.

Invalidation

fn invalidate(key: &str) -> bool {
    CACHE.lock().remove(key).is_some()
}

Call invalidate after a write so that readers never observe stale data.
